# Customer Lifetime Value Prediction

## Project Description
This project aims to analyze customer purchasing behavior and predict Customer Lifetime Value (CLV) using historical transaction data.

It implements two approaches:
- **Simple CLV Model**
- **BG/NBD + Gamma-Gamma Model**

It also includes customer segmentation and data visualizations.

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd customer_lifetime_value_group
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Execution

Run the main script:

```bash
python main.py
```

## Dataset
The project uses the Online Retail dataset for customer behavior analysis and CLV prediction.
